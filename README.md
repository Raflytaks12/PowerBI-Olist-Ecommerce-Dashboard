# 📊 E-Commerce Sales Dashboard

## 📌 Overview

This project is an interactive Power BI dashboard built to analyze the Brazilian Olist E-Commerce dataset using SQL and Google BigQuery.

---

## 🛠️ Tools & Technologies

- Power BI
- Google BigQuery
- SQL
- Data Visualization

---

## 📈 Key Performance Indicators (KPIs)

- 💰 Total Revenue
- 📦 Total Orders
- ⭐ Average Customer Rating

---

## 📊 Dashboard Features

- Monthly Revenue Trend
- Order Status Distribution
- Orders by Payment Method
- Top Product Categories by Revenue
- Top Customer Cities
- Interactive Filters (Month, Payment Type, Order Status)
